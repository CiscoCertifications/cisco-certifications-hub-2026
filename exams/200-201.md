## 1. Exam Overview & Candidate Profile

The **Cisco 200-201 CBROPS (Understanding Cisco Cybersecurity Operations Fundamentals)** exam validates the day-to-day tactical knowledge and operational skills required of an associate-level Security Operations Center (SOC) analyst. It covers cybersecurity principles, security monitoring, host-based analysis, network intrusion analysis, and security incident response procedures.

### Target Candidate Profile & Roles
* **Tier-1 SOC Analyst / Incident Responder**
* **Cybersecurity Operations Specialist**
* **Information Security Officer (Junior)**
* **Prerequisites:** No formal prerequisites. Familiarity with basic networking (TCP/IP) and Linux/Windows administration is strongly recommended.

## 4. Scenario-Based Technical Practice Questions

### Scenario 1: MITRE ATT&CK Framework Mapping
**Question:** During an active incident investigation, a SOC analyst discovers that an attacker executed a PowerShell script that harvested cleartext passwords from the Local Security Authority Subsystem Service (LSASS) process memory. Under the MITRE ATT&CK enterprise matrix, which tactic and technique correspond to this activity?

* A. Tactic: Initial Access | Technique: Phishing
* B. Tactic: Credential Access | Technique: OS Credential Dumping: LSASS Memory (T1003.001)
* C. Tactic: Lateral Movement | Technique: Remote Services: SMB/Windows Admin Shares
* D. Tactic: Defense Evasion | Technique: Obfuscated Files or Information

**Correct Answer:** **B**

**In-Depth Architectural Explanation:**
* **Why B is correct:** In the MITRE ATT&CK framework, extracting credentials directly from memory structures (specifically the LSASS process where Windows caches domain and local logon secrets) falls squarely under the **Credential Access** tactic (TA0006) and the specific technique **OS Credential Dumping: LSASS Memory** (T1003.001).
* **Distractor Analysis:**
  * Option A describes how an adversary gains an initial foothold in the environment, not credential harvesting.
  * Option C describes moving between hosts across the internal network once credentials have already been acquired.
  * Option D relates to hiding malicious payloads from security scanners, not the specific act of extracting memory hashes.

### Scenario 2: DNS Tunneling Detection via NetFlow and PCAP
**Question:** A SOC analyst reviews anomalous network traffic generated by an internal host. The host is issuing tens of thousands of high-frequency DNS queries for randomly generated, long subdomains such as `a9f82d1c.data.attacker-c2.net` to an external resolver. The TXT responses return large base64-encoded strings. What type of malicious activity is occurring?

* A. Fast-Flux DNS hosting
* B. DNS Amplification DDoS attack
* C. DNS Tunneling and data exfiltration
* D. Domain Generation Algorithm (DGA) for sinkholing

**Correct Answer:** **C**

**In-Depth Architectural Explanation:**
* **Why C is correct:** DNS Tunneling encodes non-DNS program data (such as command-and-control payloads or sensitive stolen enterprise data) into DNS query subdomains and receives responses in TXT or CNAME records. High-frequency queries with long, high-entropy subdomain strings carrying encoded payloads are the classic signature of DNS tunneling for command-and-control or exfiltration.
* **Distractor Analysis:**
  * Option A (Fast-Flux) is a technique where attackers rapidly change the A records of a domain to hundreds of rotating proxy IP addresses to evade IP-based blocking.
  * Option B (DNS Amplification) involves an external attacker sending small queries with spoofed victim source IPs to open resolvers to overwhelm the victim with large responses.
  * Option D (DGA) generates pseudo-random domain names to locate active C2 servers, but standard DGA queries do not encode two-way data payloads into subdomains and TXT payloads.

### Scenario 3: CVSS v3.1 Metric Calculation
**Question:** An enterprise vulnerability scanner detects a remote code execution vulnerability in a public-facing web server. The exploit requires no user interaction, can be executed over the internet without prior authentication, and allows an attacker to completely control the host operating system. Which CVSS v3.1 Base Metric vector elements correctly reflect this severity?

* A. `AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`
* B. `AV:L/AC:H/PR:H/UI:R/S:C/C:L/I:L/A:N`
* C. `AV:A/AC:L/PR:L/UI:N/S:U/C:H/I:N/A:N`
* D. `AV:P/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`

**Correct Answer:** **A**

**In-Depth Architectural Explanation:**
* **Why A is correct:**
  * `AV:N` (Attack Vector: Network) — Exploitable remotely over the internet.
  * `AC:L` (Attack Complexity: Low) — No specialized conditions required.
  * `PR:N` (Privileges Required: None) — No authentication required.
  * `UI:N` (User Interaction: None) — No victim action needed.
  * `C:H/I:H/A:H` (Confidentiality, Integrity, Availability: High) — Complete system takeover. This combination yields a CVSS score of 9.8 (Critical).
* **Distractor Analysis:**
  * Option B specifies Local access (`AV:L`), High complexity (`AC:H`), and High privileges required (`PR:H`), contradicting the scenario.
  * Option C specifies Adjacent network (`AV:A`) and Low confidentiality impact only (`C:L`).
  * Option D specifies Physical vector (`AV:P`), requiring physical access to the device.

### Scenario 4: Incident Response Phase Alignment (NIST SP 800-61)
**Question:** An infected laptop on the corporate network is observed making outbound connections to known ransomware command-and-control IP addresses. The SOC team immediately isolates the host's switchport to prevent lateral worm propagation before collecting a RAM image for forensic analysis. According to NIST SP 800-61 Rev. 2, which phase of incident response was just executed?

* A. Preparation
* B. Detection & Analysis
* C. Containment, Eradication, and Recovery
* D. Post-Incident Activity (Lessons Learned)

**Correct Answer:** **C**

**In-Depth Architectural Explanation:**
* **Why C is correct:** The NIST SP 800-61 incident response lifecycle consists of: 1) Preparation, 2) Detection & Analysis, 3) Containment, Eradication, and Recovery, and 4) Post-Incident Activity. Isolating a compromised endpoint from the network via switchport disabling, VLAN quarantine, or EDR network isolation is the primary objective of the **Containment** step to prevent further damage.
* **Distractor Analysis:**
  * Option A occurs before an incident occurs (training, tooling, policy definition).
  * Option B involves identifying signs of compromise and validating that an attack is occurring.
  * Option D occurs after the incident is completely resolved to evaluate organizational improvements.

### Scenario 5: Windows Security Event Log Correlation
**Question:** A cybersecurity analyst is investigating potential pass-the-hash or golden ticket attacks in an Active Directory environment. Which Windows Event ID indicates that a Kerberos ticket-granting service (TGS) request was successfully granted by the domain controller?

* A. Event ID 4624
* B. Event ID 4625
* C. Event ID 4768
* D. Event ID 4769

**Correct Answer:** **D**

**In-Depth Architectural Explanation:**
* **Why D is correct:**
  * **Event ID 4769:** "A Kerberos service ticket was requested" (TGS request). This event is logged on Domain Controllers every time a user requests access to a specific network service (such as CIFS, HTTP, or RPC) using their TGT.
* **Distractor Analysis:**
  * Option A (4624) indicates a successful account logon (interactive or network).
  * Option B (4625) indicates a failed account logon.
  * Option C (4768) indicates that a Kerberos Ticket Granting Ticket (TGT) was requested (initial authentication phase, AS-REQ/AS-REP), not the subsequent service ticket (TGS).
