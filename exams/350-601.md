## 1. Exam Overview & Candidate Profile

The **Cisco 350-601 DCCOR** exam tests a candidate's knowledge of implementing data center core technologies, including data center networking (Cisco Nexus switches), compute (Cisco UCS B-Series and C-Series), storage networking (Fibre Channel, FCoE), data center automation, and security. Passing DCCOR earns the **Cisco Certified Specialist - Data Center Core** credential, fulfills the core requirement for **CCNP Data Center**, and qualifies candidates to attempt the **CCIE Data Center** practical lab.

### Target Candidate Profile & Roles
* **Data Center Solutions Architect / Lead Engineer**
* **Cloud & Virtualization Infrastructure Administrator**
* **Nexus & UCS Storage Engineer**
* **Prerequisites:** No formal prerequisites. 3–5 years of hands-on data center infrastructure experience is typical.

## 4. Scenario-Based Technical Practice Questions

### Scenario 1: Nexus vPC Split-Brain Prevention
**Question:** In a pair of Cisco Nexus 9300 switches configured with Virtual Port Channel (vPC), the dedicated vPC Peer-Link experiences a complete physical fiber cut. However, the out-of-band vPC Peer-Keepalive link across the management network remains fully operational. How does the secondary vPC peer switch react to prevent forwarding loops?

* A. The secondary peer assumes the primary role and shuts down its own management port.
* B. The secondary peer suspends its vPC member ports, shuts down its SVIs associated with vPC VLANs, and keeps orphan ports active.
* C. Both peers shut down all physical interfaces and reboot into NX-OS recovery mode.
* D. The secondary peer continues forwarding traffic on all vPC member ports simultaneously without alteration.

**Correct Answer:** **B**

**In-Depth Architectural Explanation:**
* **Why B is correct:** When the vPC peer-link fails but the peer-keepalive link remains up, both switches can communicate health status and determine that both are alive. To prevent a "split-brain" scenario (where downstream hosts send traffic to both peers without inter-switch state synchronization), the designated **vPC secondary peer** immediately suspends all of its vPC member ports and shuts down its SVIs for vPC VLANs. All traffic is forced across the vPC primary peer.
* **Distractor Analysis:**
  * Option A describes a double failure where the secondary takes over because peer-keepalive also fails.
  * Option C is incorrect; NX-OS avoids service disruption on the primary peer.
  * Option D causes loop conditions, blackholing, and duplicate MAC address flapping across the fabric.

### Scenario 2: VXLAN EVPN Route Type Classification
**Question:** In a modern Data Center Spine-Leaf fabric utilizing VXLAN with an MP-BGP EVPN control plane (RFC 7432), which BGP EVPN route type is responsible for advertising an end-host's MAC address and optional IPv4/IPv6 host IP address binding?

* A. EVPN Route Type 1 (Ethernet Auto-Discovery)
* B. EVPN Route Type 2 (MAC/IP Advertisement)
* C. EVPN Route Type 3 (Inclusive Multicast Ethernet Tag)
* D. EVPN Route Type 5 (IP Prefix Route)

**Correct Answer:** **B**

**In-Depth Architectural Explanation:**
* **Why B is correct:** In BGP EVPN:
  * **Route Type 2** advertises MAC addresses and optionally associated IP addresses of connected workloads. This enables host MAC learning via control-plane BGP rather than data-plane flood-and-learn, and enables distributed Anycast gateway functionality.
* **Distractor Analysis:**
  * Option A (Type 1) is used for fast convergence, mass MAC withdrawal, and split-horizon filtering in multi-homing.
  * Option C (Type 3) advertises VTEP membership for handling broadcast, unknown unicast, and multicast (BUM) traffic replication.
  * Option D (Type 5) advertises routed network prefixes (subnets) rather than individual host MAC/IP bindings.

### Scenario 3: Fibre Channel Login Process
**Question:** A newly deployed Cisco UCS C-Series server with a QLogic Host Bus Adapter (HBA) powers on and connects to an MDS 9148T Fibre Channel switch. Which fabric login request must the server HBA issue first to acquire its 24-bit Fibre Channel ID (FCID) from the fabric name server?

* A. PLOGI (Port Login)
* B. PRLI (Process Login)
* C. FLOGI (Fabric Login)
* D. SCR (State Change Registration)

**Correct Answer:** **C**

**In-Depth Architectural Explanation:**
* **Why C is correct:** The Fibre Channel initialization sequence follows three distinct steps:
  1. **FLOGI (Fabric Login):** The N-Port connects to the F-Port (address `0xFFFFFE`) on the switch, exchanges buffer-to-buffer credits, and the switch assigns the server its unique 24-bit Fibre Channel ID (FCID).
  2. **PLOGI (Port Login):** The initiator establishes communication with target ports (storage controllers) or the Name Server (`0xFFFFFC`).
  3. **PRLI (Process Login):** The initiator negotiates SCSI-3 or FCP upper-layer protocols with the storage array.
* **Distractor Analysis:**
  * Option A (PLOGI) occurs after FLOGI to establish session parameters with specific targets.
  * Option B (PRLI) occurs after PLOGI to negotiate protocol-specific parameters.
  * Option D (SCR) registers the node to receive RSCN (Registered State Change Notification) alerts.

### Scenario 4: Cisco ACI Object Hierarchy
**Question:** In Cisco Application Centric Infrastructure (ACI), what is the correct logical containment relationship between policy model objects from broadest to most specific?

* A. Tenant -> VRF -> Bridge Domain -> Subnet -> Application Profile -> Endpoint Group (EPG)
* B. Tenant -> Bridge Domain -> VRF -> Endpoint Group (EPG) -> Application Profile
* C. Application Profile -> Tenant -> VRF -> Bridge Domain -> Endpoint Group (EPG)
* D. VRF -> Tenant -> Bridge Domain -> Endpoint Group (EPG) -> Contract

**Correct Answer:** **A**

**In-Depth Architectural Explanation:**
* **Why A is correct:** In the Cisco ACI Management Information Tree (MIT):
  * **Tenant:** Logical container for isolation (e.g., Common, Infra, user tenants).
  * **VRF:** Layer 3 routing context within a Tenant.
  * **Bridge Domain (BD):** Layer 2 forwarding domain linked to a VRF, which contains one or more **Subnets**.
  * **Application Profile (AP):** Container grouping related application tiers.
  * **Endpoint Group (EPG):** Collection of endpoints with identical security and policy requirements.
* **Distractor Analysis:**
  * Options B, C, and D violate the APIC object containment model schema.

### Scenario 5: Cisco Intersight Management Architecture
**Question:** An enterprise adopts Cisco Intersight for cloud-based systems management across globally distributed Cisco UCS domains. How do on-premise UCS Fabric Interconnects establish secure telemetry and management sessions with the Cisco Intersight cloud portal?

* A. Intersight dials in via inbound SSH port 22 directly through enterprise perimeter firewalls.
* B. On-premise Device Connectors initiate outbound HTTPS (TLS port 443) connections to `intersight.com`.
* C. UCS Fabric Interconnects establish an IPsec site-to-site VPN to Cisco's AWS VPC.
* D. A dedicated on-premise physical jump box proxies SNMPv3 traps to Cisco Intersight.

**Correct Answer:** **B**

**In-Depth Architectural Explanation:**
* **Why B is correct:** Cisco Intersight eliminates the need for inbound firewall holes. The built-in **Device Connector** embedded in UCS Fabric Interconnect firmware initiates a secure, outbound-only HTTPS (TLS 1.2/1.3 on TCP port 443) connection to the Cisco Intersight SaaS platform (`intersight.com`), authenticating via one-time device claim tokens.
* **Distractor Analysis:**
  * Option A is a severe security violation rejected by enterprise security standards.
  * Option C is incorrect; Intersight does not require VPN tunnels.
  * Option D is obsolete and unnecessary with modern cloud-native Device Connectors.
