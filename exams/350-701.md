## 1. Exam Overview & Candidate Profile

The **Cisco 350-701 SCOR** exam tests a candidate's knowledge of implementing and operating core security technologies, including network security, cloud security, content security, endpoint protection, secure network access, visibility, and enforcement. Passing SCOR earns the **Cisco Certified Specialist - Security Core** credential, satisfies the core requirement for **CCNP Security**, and serves as the qualifying exam for the **CCIE Security** practical lab.

### Target Candidate Profile & Roles
* **Senior Network Security Engineer**
* **Security Solutions Architect**
* **Cybersecurity Operations Engineer**
* **Prerequisites:** No formal prerequisites. 3–5 years implementing enterprise security solutions is recommended.

## 4. Scenario-Based Technical Practice Questions

### Scenario 1: Cisco ISE 802.1X Authentication Protocol Negotiation
**Question:** An enterprise deploys 802.1X port-based authentication on campus switches using Cisco ISE. The security policy mandates mutual certificate-based authentication without transmitting user passwords over the wire. Which Extensible Authentication Protocol (EAP) method must be configured?

* A. EAP-MD5
* B. PEAP-MSCHAPv2
* C. EAP-TLS
* D. EAP-GTC

**Correct Answer:** **C**

**In-Depth Architectural Explanation:**
* **Why C is correct:** **EAP-TLS (Transport Layer Security, RFC 5216)** is the gold standard for zero-trust 802.1X authentication because it enforces **mutual authentication** using X.509 digital certificates. Both the RADIUS server (Cisco ISE) and the supplicant (client endpoint) must validate each other's certificates signed by a trusted PKI CA. No passwords are used or transmitted.
* **Distractor Analysis:**
  * Option A (EAP-MD5) provides one-way client authentication only, does not support certificates, and is vulnerable to dictionary attacks.
  * Option B (PEAP-MSCHAPv2) uses a server-side certificate to create a TLS tunnel, but authenticates the user inside the tunnel using MS-CHAPv2 password hashes.
  * Option D (EAP-GTC) is an inner method used with token cards or one-time passwords, not mutual PKI certificate validation.

### Scenario 2: Cisco Firepower Threat Defense (FTD) Rule Processing Order
**Question:** In Cisco Firepower Management Center (FMC), an administrator evaluates packet processing through an Access Control Policy (ACP). In what exact order does the FTD Snort engine evaluate traffic?

* A. Intrusion Policy -> Identity Policy -> Security Intelligence -> Access Control Rules
* B. Security Intelligence -> Identity Policy -> Access Control Rules -> Intrusion / File Policy
* C. Access Control Rules -> Security Intelligence -> Intrusion Policy -> Identity Policy
* D. File Policy -> Intrusion Policy -> Security Intelligence -> Access Control Rules

**Correct Answer:** **B**

**In-Depth Architectural Explanation:**
* **Why B is correct:** Cisco FTD processes ingress connections through a strict pipeline:
  1. Pre-filter policy (Layer 2-4 fast-pathing or dropping).
  2. **Security Intelligence (SI)** (early dropping of known malicious IPs, URLs, and DNS queries to save CPU).
  3. **Identity Policy** (passive or active user authentication).
  4. **Access Control Rules** (evaluated top-to-bottom for the first matching rule: Monitor, Allow, Trust, Block).
  5. Deep inspection policies (**Intrusion Policy with Snort rules** and **File Policy with AMP inspection**) applied to allowed traffic.
* **Distractor Analysis:**
  * Options A, C, and D misrepresent the evaluation pipeline. Deep packet inspection (Intrusion/File) is resource-intensive and only occurs *after* rules allow the connection.

### Scenario 3: Email Authentication with SPF, DKIM, and DMARC
**Question:** An enterprise detects that malicious third parties are sending phishing emails with a forged `From: billing@enterprise.com` address. Which DNS record should the enterprise publish to instruct receiving mail servers to automatically quarantine or reject unaligned emails that fail SPF or DKIM checks?

* A. An SPF TXT record: `v=spf1 include:_spf.enterprise.com -all`
* B. A DMARC TXT record: `_dmarc.enterprise.com` with value `v=DMARC1; p=reject; rua=mailto:dmarc-reports@enterprise.com`
* C. A DKIM TXT record specifying public key exponent `k=rsa`
* D. An MX record pointing to Cisco Secure Email Cloud Gateway

**Correct Answer:** **B**

**In-Depth Architectural Explanation:**
* **Why B is correct:** While SPF verifies the sending IP against authorized envelope domains and DKIM cryptographically signs message headers, neither protocol dictates what a receiving server should do with failures. **DMARC (Domain-based Message Authentication, Reporting, and Conformance)** bridges this gap. By publishing a DMARC policy with `p=reject`, the domain owner instructs receiving mail gateways to reject any incoming message whose `From:` header domain fails alignment with SPF or DKIM.
* **Distractor Analysis:**
  * Option A defines allowed sending hosts in SPF, but does not provide domain alignment enforcement or reporting.
  * Option C publishes a cryptographic public key for signature verification without dictating policy enforcement.
  * Option D defines inbound mail routers for the enterprise domain.

### Scenario 4: Cisco Umbrella Roaming Client Architecture
**Question:** A remote workforce with off-network laptops experiences malware infections while working from public Wi-Fi networks. The organization deploys Cisco Umbrella Roaming Client. How does this client protect user traffic?

* A. It establishes a full-tunnel IPsec VPN back to the corporate Cisco ASA headend for all traffic.
* B. It intercepts all DNS queries on `127.0.0.1:53` and redirects them via encrypted Anycast DNS (port 443/53) to Cisco Umbrella resolvers for cloud inspection.
* C. It installs a local antivirus signature database updated every hour from Cisco Talos.
* D. It disables the laptop's Wi-Fi adapter when untrusted access points are detected.

**Correct Answer:** **B**

**In-Depth Architectural Explanation:**
* **Why B is correct:** The Cisco Umbrella Roaming Client is a lightweight endpoint daemon that binds to the local loopback address (`127.0.0.1`) and sets the local DNS resolver to itself. It intercepts all outbound DNS requests, encapsulates them with client identification metadata, and forwards them securely to Cisco Umbrella global Anycast IP addresses (`208.67.222.222` / `208.67.220.220`). Malicious domains are blocked at the DNS layer before any IP connection can be established.
* **Distractor Analysis:**
  * Option A describes a traditional full-tunnel Remote Access VPN, not Umbrella's cloud DNS architecture.
  * Option C describes signature-based antivirus solutions (e.g., ClamAV).
  * Option D is non-standard behavior that would eliminate remote user connectivity.

### Scenario 5: Cisco TrustSec Inline Tagging & SGT Propagation
**Question:** Two departments in an enterprise, Finance (SGT 10) and Human Resources (SGT 20), are separated by a campus switch infrastructure. Security policy enforces segmentation using Security Group ACLs (SGACLs). Where in the Ethernet frame is the Scalable Group Tag (SGT) transported when traversing native Layer 2 switch uplinks?

* A. Inside the 802.1Q VLAN Tag Priority Code Point (PCP) field.
* B. Inside the Cisco CMD (Cisco Meta Data) field inserted between the Layer 2 header and Layer 3 payload.
* C. Inside the IP header Type of Service (ToS) byte.
* D. Inside the TCP Options header.

**Correct Answer:** **B**

**In-Depth Architectural Explanation:**
* **Why B is correct:** Cisco TrustSec implements hardware-based inline tagging using **Cisco Meta Data (CMD)**. When a frame exits a TrustSec-enabled switchport configured for Cisco Transport Security (CTS), the ASIC inserts an 8-byte CMD header (EtherType `0x8909`) directly into the Layer 2 frame between the MAC header and the payload. This header carries the 16-bit Scalable Group Tag (SGT) across the network.
* **Distractor Analysis:**
  * Option A (802.1Q PCP) is a 3-bit field used strictly for Layer 2 Class of Service (CoS) QoS marking.
  * Option C (IP ToS / DSCP) is used for Layer 3 QoS classification.
  * Option D is part of the transport layer and cannot be processed at wire speed by Layer 2 transit switches.
